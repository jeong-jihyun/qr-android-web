> 작성일: 2026-08-26
> 목적: 내일 반영할 소스 변경사항을 그대로 붙여넣기 가능한 수준으로 정리

## 0. 전체 구조 요약

```
[HANIS-SM530 (블루투스 HID)] ──┐
[Zebra 핸드헬드 (DataWedge)]   ──┼──▶ processScanData(data, source) ──▶ WebView(JS)로 전달
[Zebra 핸드헬드 (EMDK, 백업용)] ──┘
```

- 세 가지 입력 경로 모두 **하나의 공통 함수**로 모음
- WebView 쪽 코드는 스캐너 종류를 몰라도 되고, `onScanReceived(data)` 함수 하나만 받으면 됨

## 3. MainActivity.java (전체)

```java
package com.myapp;

import android.app.Activity;
import android.content.IntentFilter;
import android.os.Bundle;
import android.os.Handler;
import android.os.Looper;
import android.text.Editable;
import android.text.InputType;
import android.text.TextWatcher;
import android.webkit.WebView;
import android.widget.EditText;

public class MainActivity extends Activity {

    private WebView webView;
    private EditText hiddenInput;

    private final Handler scanTimeoutHandler = new Handler(Looper.getMainLooper());
    private static final long SCAN_IDLE_TIMEOUT_MS = 150;

    private String lastScanData = "";
    private long lastScanTime = 0;

    private final ScanReceiver scanReceiver = new ScanReceiver(this);

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        webView = findViewById(R.id.webView);
        webView.getSettings().setJavaScriptEnabled(true);
        webView.loadUrl("file:///android_asset/index.html"); // 또는 서버 URL로 교체

        hiddenInput = findViewById(R.id.hiddenInput);
        hiddenInput.setInputType(InputType.TYPE_CLASS_TEXT | InputType.TYPE_TEXT_FLAG_MULTI_LINE);
        hiddenInput.requestFocus();

        hiddenInput.addTextChangedListener(new TextWatcher() {
            @Override
            public void afterTextChanged(Editable s) {
                scanTimeoutHandler.removeCallbacksAndMessages(null);
                scanTimeoutHandler.postDelayed(() -> {
                    String scanned = hiddenInput.getText().toString();
                    if (!scanned.trim().isEmpty()) {
                        processScanData(scanned.trim(), "HANIS-HID");
                        hiddenInput.setText("");
                    }
                }, SCAN_IDLE_TIMEOUT_MS);
            }
            @Override public void beforeTextChanged(CharSequence s, int a, int b, int c) {}
            @Override public void onTextChanged(CharSequence s, int a, int b, int c) {}
        });

        registerReceiver(scanReceiver, new IntentFilter("com.myapp.SCAN"));
    }

    @Override
    protected void onResume() {
        super.onResume();
        hiddenInput.requestFocus(); // 포커스 뺏겼을 경우 복구
    }

    @Override
    protected void onDestroy() {
        super.onDestroy();
        unregisterReceiver(scanReceiver);
    }

    // ===== 모든 스캐너 입력의 공통 종착점 =====
    public void processScanData(String data, String source) {
        if (data == null || data.trim().isEmpty()) return;
        String scanned = data.trim();
        long now = System.currentTimeMillis();

        // 300ms 내 동일 데이터 중복 무시
        if (scanned.equals(lastScanData) && (now - lastScanTime) < 300) {
            return;
        }
        lastScanData = scanned;
        lastScanTime = now;

        // WebView(JS)로 전달
        String escaped = scanned.replace("\\", "\\\\").replace("'", "\\'");
        webView.evaluateJavascript("onScanReceived('" + escaped + "')", null);
    }
}
```

## 4. ScanReceiver.java (DataWedge 수신용)

```java
package com.myapp;

import android.content.BroadcastReceiver;
import android.content.Context;
import android.content.Intent;

public class ScanReceiver extends BroadcastReceiver {

    private final MainActivity activity;

    public ScanReceiver(MainActivity activity) {
        this.activity = activity;
    }

    @Override
    public void onReceive(Context context, Intent intent) {
        if ("com.myapp.SCAN".equals(intent.getAction())) {
            String scanData = intent.getStringExtra("com.symbol.datawedge.data_string");
            activity.processScanData(scanData, "Zebra-DataWedge");
        }
    }
}
```

## 6. (선택) Zebra EMDK 병행 시 추가 코드

DataWedge만으로 충분하면 이 섹션은 생략 가능. EMDK도 백업 경로로 같이 쓸 경우:

```java
private EMDKManager emdkManager;
private BarcodeManager barcodeManager;
private Scanner scanner;

private void initEmdk() {
    EMDKManager.getEMDKManager(getApplicationContext(), new EMDKManager.EMDKListener() {
        @Override
        public void onOpened(EMDKManager manager) {
            emdkManager = manager;
            new Thread(() -> initScanner(manager)).start();
        }
        @Override
        public void onClosed() {
            if (scanner != null) {
                try { scanner.disable(); } catch (Exception e) { e.printStackTrace(); }
            }
        }
    });
}

private void initScanner(EMDKManager manager) {
    barcodeManager = (BarcodeManager) manager.getInstance(EMDKManager.FEATURE_TYPE.BARCODE);
    scanner = barcodeManager.getDevice(BarcodeManager.DeviceIdentifier.DEFAULT);
    try {
        scanner.addDataListener(scanDataCollection -> {
            if (scanDataCollection != null && scanDataCollection.getResult() == ScannerResults.SUCCESS) {
                for (ScanDataCollection.ScanData scanData : scanDataCollection.getScanData()) {
                    String barcode = scanData.getData();
                    runOnUiThread(() -> processScanData(barcode, "Zebra-EMDK"));
                }
            }
        });
        scanner.enable();
    } catch (ScannerException e) {
        e.printStackTrace();
    }
}

@Override
protected void onDestroy() {
    super.onDestroy();
    try {
        if (scanner != null) scanner.disable();
        if (emdkManager != null) emdkManager.release();
    } catch (Exception e) {
        e.printStackTrace();
    }
}
```
